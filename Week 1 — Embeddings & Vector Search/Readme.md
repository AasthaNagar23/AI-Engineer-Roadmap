# Smart Knowledge Search Engine
A semantic document search system that retrieves relevant information based on meaning rather than exact keyword matching.

How It Works:
Documents -> Text Extraction -> Recursive Chunking -> Embeddings ->FAISS Vector Index -> User Query -> Query Embedding -> Similarity Search -> Top K Relevant Chunks

Tech Stack:
1. Python
2. Sentence Transformers
3. FAISS
4. NumPy
5. PDF/Text Processing

Key Concepts:
1. Text chunking and metadata
2. Text embeddings
3. Semantic similarity
4. Vector search
5. FAISS
6. Top-K retrieval

Goal:
To build a practical understanding of the embedding -> vector search -> retrieval pipeline used in modern AI applications and as the foundation for future RAG systems.

Future Scope:
RAG, hybrid search, reranking, retrieval evaluation, and LLM integration.
